# PostgreSQL и аккаунты Mesto

## Подключение

Приложение читает строку подключения из переменной окружения `DATABASE_URL`.
Не добавляйте настоящий пароль базы данных в GitHub.

Локальный пример:

```bash
export DATABASE_URL="postgresql://mesto_user:YOUR_PASSWORD@localhost:5432/mesto"
```

На платформе хостинга добавьте `DATABASE_URL` в Environment Variables или Secrets.

## Схема

- `users`: имя, уникальная почта, хеш пароля и дата регистрации.
- `user_preferences`: жизненный сценарий и пользовательские веса критериев.
- `favorites`: сохранённые пользователем ячейки; одна ячейка не может дважды попасть в избранное одного пользователя.

Пароли хешируются с помощью bcrypt. Исходные пароли не сохраняются.

## Создание таблиц

Таблицы создаются через SQLAlchemy. Для первого прототипа это позволит быстро начать работу. Перед публичным запуском и последующими изменениями схемы следует добавить миграции Alembic.

## Перед публичным запуском

- Используйте управляемый PostgreSQL с резервным копированием.
- Храните `DATABASE_URL` только в секретах платформы.
- Включите HTTPS.
- Настройте ограничения частоты попыток входа и восстановление пароля.
- Для production-сессий нужен устойчивый защищённый механизм с cookie и сроком действия; одного Streamlit session state недостаточно для полноценной системы сессий.
