# Источники и подготовка геоданных

## 1. Граница города

Для первого чернового контура можно использовать OpenStreetMap через Nominatim. Это **кандидат на границу**, а не подтверждённая официальная юридическая граница. Nominatim может вернуть границу городского округа/муниципального образования вместо фактической городской застройки. Поэтому перед построением сетки проверьте название, `admin_level`, OSM ID, геометрию и соответствие исследовательскому определению города.

Официальный геопортал Магнитогорска: https://gisportal.magnitogorsk.ru/ . Проверьте, опубликован ли там подходящий контур территории. Если доступен официальный набор, предпочтите его OSM-кандидату и зафиксируйте метаданные.

Скрипт `scripts/fetch_osm_boundary.py` ищет административный полигон и отказывается автоматически выбирать его, если кандидатов несколько. Он сохраняет метаданные источника, дату получения и пометку о необходимости ручной проверки.

## 2. Построение сетки

После проверки `data/raw/city_boundary.geojson` запустите `python scripts/build_grid.py`. Результат — `data/processed/grid_cells.geojson`. Размер ячейки по умолчанию 250 м. По умолчанию сохраняются полные квадраты, центр которых находится внутри контура; `--include-partial-cells` обрезает крайние ячейки.

## 3. Инфраструктура и жилые точки

Следующий этап — загрузить точки объектов инфраструктуры и жилой застройки из OSM/официальных источников. Для каждого объекта нужно сохранять категорию, источник, дату выгрузки и лицензию. Проверяйте полноту по категориям, дубликаты и координаты. Для итогового индекса желательно использовать точки входов/жилых зданий, а не только центры ячеек.

OpenStreetMap: https://www.openstreetmap.org/ . Nominatim API: https://nominatim.org/release-docs/latest/api/Search/ . Данные OSM распространяются по ODbL 1.0: https://www.openstreetmap.org/copyright . Соблюдайте правила использования публичных сервисов и не делайте массовые запросы без необходимости.

## Ограничения

- OSM не гарантирует полноту инфраструктуры.
- Граница OSM не считается официальной без отдельного подтверждения.
- Ячейки сетки сами по себе не говорят, что территория жилая.
- Сетка не создаёт реальные оценки комфорта до загрузки и проверки инфраструктуры.
