# Источники и подготовка геоданных

## 1. Граница города

Для первого чернового контура можно использовать OpenStreetMap через Nominatim. Это **кандидат на границу**, а не подтверждённая официальная юридическая граница. Nominatim может вернуть границу городского округа/муниципального образования вместо фактической городской застройки. Перед построением сетки проверьте название, `admin_level`, OSM ID, геометрию и соответствие исследовательскому определению города.

Официальный геопортал Магнитогорска: https://gisportal.magnitogorsk.ru/ . Проверьте, опубликован ли там подходящий контур. Если доступен официальный набор, предпочтите его OSM-кандидату и зафиксируйте метаданные.

Команда получения кандидата: `python scripts/fetch_osm_boundary.py`. Скрипт сохраняет источник, дату получения и пометку о необходимости ручной проверки. Если найдено несколько кандидатов, он не выбирает случайный объект.

## 2. Построение сетки

После проверки `data/raw/city_boundary.geojson` запустите `python scripts/build_grid.py`. Результат — `data/processed/grid_cells.geojson`. Размер ячейки по умолчанию 250 м. По умолчанию сохраняются полные квадраты, центр которых находится внутри контура; `--include-partial-cells` обрезает крайние ячейки.

## 3. Инфраструктура из OpenStreetMap

После проверки границы выполните `python scripts/fetch_osm_infrastructure.py`. Скрипт получает первый набор POI через Overpass API и сохраняет `data/raw/infrastructure_osm.geojson`. Он использует предварительное сопоставление тегов OSM с критериями транспорт, образование, медицина, повседневная инфраструктура, зелёные зоны и досуг.

Это первичная выгрузка, не эталонный реестр. Некоторые категории могут быть ошибочными или неполными; например, магазины и аптеки требуют согласованного правила классификации, чтобы не учитывать один объект дважды. OSM-геометрии зданий/отношений для запроса могут быть представлены центроидами. Проверяйте выборку на карте, количество объектов по категориям, пропуски и дубликаты. Соблюдайте ограничения публичного Overpass API и не запускайте частые массовые запросы.

## 4. Жилые ячейки

Ячейка не становится жилой только потому, что попала внутрь городской границы. Для классификации жилых ячеек нужен отдельный слой жилых зданий/жилой застройки. До его появления не исключайте автоматически ячейки по догадке и не интерпретируйте всю сетку как жилую.

## Лицензии и источники

- OpenStreetMap: https://www.openstreetmap.org/
- Nominatim Search API: https://nominatim.org/release-docs/latest/api/Search/
- Overpass API: https://wiki.openstreetmap.org/wiki/Overpass_API
- OSM copyright/licence: https://www.openstreetmap.org/copyright

Для каждого файла сохраняйте дату выгрузки, URL источника, лицензию и описание преобразований. Данные OSM распространяются по ODbL 1.0.

## Ограничения

- OSM не гарантирует полноту инфраструктуры.
- Граница OSM не считается официальной без отдельного подтверждения.
- Первичная категория POI — эвристика, которую нужно проверить.
- Прямолинейное расстояние не заменяет пешие маршруты.
- Реальный индекс не следует публиковать до проверки источников, полноты и методики.
