# Источники геоданных

## Основные кандидаты

### OpenStreetMap

https://www.openstreetmap.org/

Для поиска объектов инфраструктуры и координат.

### Overpass API

https://overpass-turbo.eu/

Для выборки объектов OpenStreetMap по категориям и территории.

Документация:
https://wiki.openstreetmap.org/wiki/Overpass_API

### Портал открытых данных РФ

https://data.gov.ru/

Нужно проверить доступность наборов данных администрации
Магнитогорска и их актуальность.

## Что проверить для каждого источника

- Какие объекты доступны.
- Покрытие территории Магнитогорска.
- Формат данных.
- Дату обновления.
- Условия использования и лицензирование.
- Пропуски, дубликаты и качество координат.
