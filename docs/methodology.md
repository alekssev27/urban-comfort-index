# Методика расчёта индекса

Методика находится на этапе проектирования.

## План

1. Определить единицы территориального сравнения.
2. Собрать исходные показатели инфраструктуры.
3. Выбрать способ измерения каждого критерия.
4. Определить метод нормализации.
5. Согласовать веса трёх пользовательских профилей.
6. Реализовать взвешенный индекс.
7. Проверить расчёты на контрольных примерах.
8. Документировать ограничения и возможные смещения.

## Принцип

Итоговая оценка должна быть объяснимой: пользователь
должен видеть, какие показатели и веса повлияли на результат.

Начальные веса являются гипотезами и подлежат проверке.
