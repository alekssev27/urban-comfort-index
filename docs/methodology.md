# Методика расчёта индекса

Методика находится в разработке.

План:
1. Определить критерии оценки районов.
2. Определить исходные показатели и источники данных.
3. Выбрать способы нормализации.
4. Утвердить веса для жизненных сценариев.
5. Реализовать взвешенную оценку.
6. Проверить расчёты на контрольных примерах.
7. Документировать ограничения метода.
