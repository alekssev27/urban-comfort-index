# API Яндекса для Mesto

Проверено 14 ноября 2026 года по официальным страницам. Бесплатный доступ и временный тест платного API — разные режимы.

| Сервис | Бесплатные условия/лимиты | Применение |
|---|---|---|
| Tiles API | 30 запросов/с; открыт для коммерческих и некоммерческих систем | Лучшее соответствие текущему Folium/Leaflet. Поддержка в app.py уже есть через YANDEX_MAPS_API_KEY. |
| JavaScript API | Бесплатный режим при соблюдении условий; панорамы 100 запросов/сутки | Отдельный компонент карты, если понадобятся панорамы и сервисы Яндекса. Миграция с Folium потребует разработки. |
| Геокодер | 1000 запросов/сутки; результаты предназначены для отображения через JS API Яндекс Карт | Поиск адреса при переходе на JS API. Нельзя считать Folium с подложкой Tiles полноценной заменой требуемому JS API. |
| Геосаджест | 1000 запросов/сутки | Автодополнение адресов; отдельное подключение, задержка запросов при вводе и контроль квоты. |
| Static API | 100 запросов/сутки | Небольшие статические превью; лимит слишком мал для превью каждой территории всем посетителям. |

Источник лимитов и ограничений: [условия сервисов, раздел 6](https://yandex.ru/legal/maps_api/ru/). Tiles требует атрибуцию/логотип; имеющуюся текстовую имитацию логотипа следует сверить с документацией и заменить официальным вариантом перед использованием Яндекс-подложки. [Документация Tiles](https://yandex.ru/maps-api/docs/tiles-api/index.html), [страница продукта](https://yandex.ru/maps-api/products/tiles-api).

**Рекомендация:** оставить OSM источником расчётной базы, Tiles — опциональной подложкой. Бесплатный Геокодер не подходит для массового наполнения постоянного CSV адресами. Возможность временного кэша не означает разрешения создавать собственную базу данных из ответов. [Объяснение условий бесплатного использования](https://yandex.ru/dev/commercial/doc/ru/).

Не переносить старую цифру «25 000 запросов в сутки» на все сервисы. Продукты подключаются отдельно; условия для ключей до и после 20.04.2025 различаются. [Официальное описание изменения](https://yandex.ru/maps-api/docs/news/new-billing/free-usage.html).

**Не закладывать как постоянный бесплатный источник:** API Поиска по организациям, матрицы расстояний, детали маршрутов и изохроны. В проверенных общих бесплатных условиях они не дают основания обещать бесплатный массовый расчёт; нужно проверять отдельный продукт и тариф в кабинете. Для научно воспроизводимых пеших расстояний лучше исследовать маршрутизацию по OSM отдельно.

**Погода:** официальные тарифы предлагают бесплатный тест на 7 дней; это не постоянный бесплатный API. Погода всего города также слабо различает соседние ячейки. [Тарифы API Погоды](https://yandex.ru/dev/weather/doc/ru/concepts/pricing?lang=ru).

Новых сервисов и платных подписок не подключено. Локальный просмотр использует OpenStreetMap, так как ключ Яндекса не настроен. Для следующего этапа: оформить Tiles в кабинете, настроить разрешённые домены ключа, проверить официальную атрибуцию, ошибки квоты и переключение на OSM. Ключ браузерных тайлов виден клиенту по природе API; его нельзя считать серверным секретом, ограничение по домену существенно.
