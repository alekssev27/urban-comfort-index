# Индекс комфорта городской среды

Студенческий проект: прототип персонализированной оценки
комфорта городской среды для города Магнитогорска.

## Цель проекта

Разработать интерактивный сервис, который оценивает районы
с учётом жизненного сценария пользователя и характеристик
городской инфраструктуры.

## Основные функции

- Интерактивная карта районов Магнитогорска.
- Профили: студент, пара, семья с детьми.
- Расчёт персонализированного индекса комфорта.
- Настройка весов критериев.
- Сравнение районов.
- Визуализация инфраструктуры и результатов анализа.
- Кластеризация районов (дополнительная функция).

## Технологии

- Python
- Streamlit
- Pandas, GeoPandas
- Folium, Streamlit-Folium
- Plotly
- Scikit-learn
- Pytest

## Структура проекта

- `app.py` — главная страница приложения.
- `pages/` — дополнительные страницы.
- `src/` — расчёты, обработка данных и аналитика.
- `data/raw/` — исходные данные.
- `data/processed/` — подготовленные данные.
- `tests/` — автоматические тесты.
- `docs/` — документация и методология.

## Установка

Требуется установленный Python 3.11 или новее.

Создайте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Запуск

```bash
streamlit run app.py
```

## Тестирование

```bash
pytest
```
