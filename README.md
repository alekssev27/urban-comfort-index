# Индекс комфорта городской среды

Студенческий проект: прототип персонализированной оценки городской среды Магнитогорска.

## Цель

Помочь сравнивать городские территории с учётом жизненного сценария пользователя и доступности инфраструктуры. Основная пространственная единица новой версии — квадратная ячейка сетки 250 × 250 м, а не административный район.

## Возможности прототипа

- Streamlit-интерфейс и интерактивная карта Folium.
- Профили: студент, пара, семья с детьми.
- Настройка весов шести критериев: транспорт, образование, медицина, зелёные зоны, повседневная инфраструктура и досуг.
- Расчёт взвешенного индекса и сравнение оценок.
- Генерация квадратной сетки в метрической проекции (см. `src/grid.py`).
- Базовый расчёт прямолинейного расстояния до инфраструктуры (см. `src/accessibility.py`).

## Важно о данных

`data/demo_scores.csv` содержит синтетические значения для демонстрации интерфейса. Они не являются результатом исследования Магнитогорска. Проверенный контур города, реальные жилые точки, инфраструктура и пешеходная сеть пока должны быть подключены. Поэтому приложение ещё не выдаёт достоверный индекс для каждой ячейки города.

## Структура

- `app.py` — приложение Streamlit.
- `src/scoring.py` — расчёт взвешенного индекса.
- `src/data_loader.py` — загрузка и проверка демонстрационных оценок.
- `src/grid.py` — генерация ячеек 250 × 250 м из предоставленной геометрии.
- `src/accessibility.py` — базовый расчёт прямолинейных расстояний и пробных оценок.
- `data/raw/` — исходные геоданные; проверяйте лицензии и не публикуйте запрещённые данные.
- `data/processed/` — подготовленные данные.
- `tests/` — автоматические тесты.
- `docs/` — методология и требования к данным.

## Установка

Требуется Python 3.11 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Запуск приложения

```bash
streamlit run app.py
```

## Тесты

```bash
pytest -q
```

## Следующие этапы

1. Получить проверенную границу территории исследования и зафиксировать источник, дату и лицензию.
2. Получить точки жилых зданий и инфраструктуры с метаданными источника.
3. Проверить геометрию и координатную систему, сгенерировать `grid_cells.geojson`.
4. Рассчитать доступность по пешеходной сети; прямолинейное расстояние пока является лишь приближением.
5. Рассчитать индекс с явным показателем полноты данных и проверить пороги/веса.
6. Подключить полигоны и оценки ячеек к карте Streamlit.
