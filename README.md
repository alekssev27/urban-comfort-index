# Индекс комфорта городской среды

Студенческий проект: прототип персонализированной оценки городской среды Магнитогорска.

## Цель

Помочь сравнивать территории с учётом жизненного сценария пользователя и доступности инфраструктуры. Основная пространственная единица — квадратная ячейка 250 × 250 м, а не административный район.

## Возможности прототипа

- Streamlit-интерфейс и карта Folium.
- Профили: студент, пара, семья с детьми.
- Настройка весов критериев: транспорт, образование, медицина, зелёные зоны, повседневная инфраструктура и досуг.
- Расчёт взвешенного индекса и сравнение оценок.
- Генерация сетки из предоставленного полигона (`src/grid.py`).
- Базовые прямолинейные расстояния до инфраструктуры (`src/accessibility.py`).

## Подготовка реальной географии

1. Установите зависимости: `python -m pip install -r requirements.txt`.
2. Попробуйте получить кандидат границы из OpenStreetMap: `python scripts/fetch_osm_boundary.py`.
3. **Откройте `data/raw/city_boundary.geojson` и проверьте геометрию и метаданные.** Если скрипт сообщил о нескольких кандидатах, выберите подходящий объект вручную и повторите запрос с `--osm-id` и `--osm-type`.
4. После проверки постройте сетку: `python scripts/build_grid.py`.
5. Для первого слоя POI выполните `python scripts/fetch_osm_infrastructure.py`; результат появится в `data/raw/infrastructure_osm.geojson`.
6. Результат сетки появится в `data/processed/grid_cells.geojson`.

Контур OSM является кандидатом, а не автоматически официальной границей. Сравните его с официальным геопорталом города: https://gisportal.magnitogorsk.ru/ . Документация: [`docs/data-sources.md`](docs/data-sources.md).

## Важно о данных

`data/demo_scores.csv` содержит синтетические значения для демонстрации интерфейса. Реальная инфраструктура и жилые точки ещё не подключены, поэтому проект пока не выдаёт достоверный рейтинг ячеек Магнитогорска. Сгенерированная сетка также не означает, что каждая ячейка жилая.

## Структура

- `app.py` — приложение Streamlit.
- `src/scoring.py` — расчёт взвешенного индекса.
- `src/data_loader.py` — загрузка демонстрационных оценок.
- `src/grid.py` — генерация ячеек 250 × 250 м.
- `src/accessibility.py` — прямолинейные расстояния и предварительные оценки.
- `scripts/fetch_osm_boundary.py` — получение кандидата границы.
- `scripts/build_grid.py` — построение сетки.
- `data/raw/` — исходные геоданные.
- `data/processed/` — подготовленные данные.
- `tests/` — автоматические тесты.
- `docs/` — методика и источники.

## Запуск интерфейса

```bash
streamlit run app.py
```

## Тестирование

```bash
python -m pytest -q
```

## Ограничения и следующие этапы

- Подтвердить границу исследования и задокументировать источник/лицензию.
- Получить жилые здания/входы и объекты инфраструктуры с источниками и датами.
- Рассчитать доступность по пешеходной сети; прямолинейные расстояния — только приближение.
- Определить жилые ячейки по данным застройки, не по одному факту попадания в контур.
- Показывать полноту данных вместе с индексом и не смешивать синтетические данные с реальными.
